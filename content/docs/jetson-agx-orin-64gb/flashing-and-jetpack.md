## 操作边界与安全提示

本页提供系统刷写前的核对清单，不指定板级命令、刷写目标或存储设备名。执行具体步骤前，应取得实际载板适用的操作说明。

> 系统刷写可能改写存储内容。先备份用户数据、应用配置与需要保留的文件，并确认可恢复方案；不要在尚未核对目标设备时执行写入操作。

## 选择适用版本

1. 记录模组、载板与当前系统信息，说明本次目的是首次部署、恢复系统还是升级。
2. 打开[JetPack SDK 下载与支持说明](https://developer.nvidia.com/embedded/jetpack/downloads)，核对目标 JetPack 分支是否支持所用硬件。
3. 对新部署，按该分支的安装入口继续查阅；对既有项目的复现或恢复，使用与交付镜像相同版本的官方说明，避免混用不同分支步骤。
4. 核对载板供应方提供的镜像与配置适用版本。遇到差异时先协调版本，再开始操作。

## Host OS 与安装入口分支

| 实际情况 | 核对与下一步 |
| --- | --- |
| 所选官方安装流程需要主机 | 查阅该流程对应版本的 Host OS 要求、工具要求与设备连接方式。主机条件匹配后再继续。 |
| 主机系统不在所选流程支持范围内 | 先准备符合要求的主机，或核对官方是否提供适用的其他安装入口；不要根据其他版本推断兼容。 |
| 使用原装 AGX Orin 开发套件 | 结合[开发套件快速开始](https://docs.nvidia.com/jetson/agx-orin-devkit/user-guide/latest/quick_start.html)核对硬件准备和安装入口。 |
| 使用第三方或自研载板 | 先取得相应载板版本的配置与说明，结合[Jetson 官方 FAQ](https://developer.nvidia.com/embedded/faq)核对适配边界。 |

本文不列固定 Ubuntu 版本、JetPack 大版本或恢复模式操作组合；这些条件必须在选定安装分支及实际硬件说明中核对。

## 执行前后检查

1. 确认备份可用、目标设备明确、供电连接符合硬件说明。
2. 按已经核对的官方流程及载板说明操作，保留工具输出和错误信息。
3. 完成后核对系统版本、启动状态与应用依赖，再验证业务需要的外设。
4. 若结果不符合预期，记录硬件型号、软件版本、操作阶段和完整错误信息，提交给交付支持人员分析。

## 适用范围与安全提示

本页用于 AGX Orin 64GB 量产模组项目的接口需求整理。模组规格中的接口能力，需要结合实际载板连接、器件与软件配置核对；不能直接视为整机已引出的可用接口。

> 接线前核对载板接口定义、电气条件与外设说明。引脚定义或供电条件不明确时，先向供应方确认；本文不提供自研载板接线图或未经核对的引脚号。

## 核对顺序

1. 在[Jetson Orin 官方产品规格](https://www.nvidia.com/en-us/autonomous-machines/embedded-systems/jetson-orin/)定位 AGX Orin 64GB，记录业务需要的接口类别。
2. 阅读[Jetson 官方 FAQ](https://developer.nvidia.com/embedded/faq)中的载板适配说明，并取得实际载板对应修订版的接口资料。
3. 将外设清单与载板实际引出的连接器逐项对应，核对连接方式、电气条件和所需附件。
4. 通过[JetPack SDK 下载与支持说明](https://developer.nvidia.com/embedded/jetpack/downloads)定位所选软件分支，并与载板供应方确认驱动和配置要求。
5. 在完整交付配置上验证实际业务负载，记录通过条件和未解决事项。

## 外设检查表

| 检查项目 | 项目需要记录的信息 |
| --- | --- |
| 摄像头与采集设备 | 设备型号、连接方式、驱动来源、目标输入条件 |
| 网络设备 | 连接器、网络配置、业务带宽与稳定性验证结果 |
| 存储设备 | 介质型号、连接方式、镜像部署要求与数据保留需求 |
| 显示与调试设备 | 载板引出接口、连接附件、供应方操作说明 |
| 其他控制外设 | 接口定义、电气条件、驱动与应用依赖 |

检查表是需求整理模板，不表示任一载板默认具备上述全部接口。

## 适用版本与验收记录

本文不绑定特定载板或 JetPack 版本。验收时记录模组型号、载板修订号、系统与驱动版本、外设固件、测试输入及结果。硬件或软件发生变化后，重新核对受影响的接口。
